    Start Here¶

    New to Soft Potato? You do not need to write differential equations or build numerical meshes to get started. Use the decision table below to jump straight to the right API and documentation section for your goal.

    Which Tool Should I Use?¶

    Soft Potato is organized in layers—from one-line closed-form equations up to custom multi-species PDE solvers. Pick the row that matches what you want to do:

    If you want to… Use Typical inputs Where to go next
    Compute an exact theoretical baseline (Cottrell, Randles–Ševčík, Levich, Butler–Volmer, microelectrodes, SECM) softpotato.analytical Physical constants (\(D\), \(c^*\), \(n\), \(A\), \(v\), \(\omega\)) User Guide · API Reference
    Extract \(D\), \(k^0\), \(\alpha\), or \(RG\) from experimental data with confidence intervals and \(R^2\) softpotato.analytical.fitting Experimental arrays (t, i, E, v, omega) User Guide · API Reference
    Simulate a standard electrochemical experiment (CA, LSV, CV, SCV, DPV, SWV, CP, RDE) with automatic plotting and diagnostics softpotato.techniques.simulate() Waveform object (e.g. CyclicVoltammetry(...)) + physical parameters User Guide · Tutorials
    Build a custom reaction–diffusion model with bespoke grids, geometries, boundary conditions, or PDE solvers softpotato.solver.DiffusionProblem() Spatial grid (grid), diffusivity, boundary_conditions, initial_conditions, reactions / mechanism Concepts · Tutorials

    Chip's Tip

    If you are unsure where to start, begin with softpotato.analytical for quick reference curves or softpotato.techniques.simulate() for full voltammetric and transient simulations. Drop down to DiffusionProblem() only when you need custom meshes, non-standard boundary conditions, or custom solver settings.

    Try Soft Potato Right Now¶

    Run Soft Potato directly in your browser with nothing to install on your computer:

    Launch Soft Potato v3 Starter in Google Colab Google Colab Guide

    Install the latest stable release from PyPI:

    pip install softpotato

    Verify your installation in Python:

    import softpotato as sp

print(sp.__version__)
