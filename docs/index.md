## Choose Your Path

Whether you are running your first simulation from the laboratory bench or building custom multi-species reaction–diffusion models, pick the path that matches your background:

<div class="grid cards" markdown>

-   ![Experimentalist](assets/images/chip-lab.png){ .sp-card-icon } **Experimentalist** *(No Programming Experience)*

    ---

    New to Python or numerical modelling? Start in your browser with Google Colab, install Soft Potato step by step, and use the decision guide to pick the right tool for your experiment.

    [:octicons-arrow-right-24: Go to Start Here](start-here/index.md)

-   ![Python User](assets/images/chip-electrodes.png){ .sp-card-icon } **Python User** *(No Modelling Experience)*

    ---

    Comfortable with basic Python and ready to simulate CV, LSV, CA, pulse techniques, RDE, or fit experimental datasets? Follow task-oriented workflows using `softpotato.techniques` and `softpotato.analytical`.

    [:octicons-arrow-right-24: Go to User Guide](user-guide/index.md)

-   ![Computational Modeller](assets/images/chip-coding.png){ .sp-card-icon } **Computational Modeller**

    ---

    Want full control over non-uniform meshes, spherical/cylindrical geometries, coupled reaction mechanisms, and stiff PDE solvers? Explore the underlying theory and interactive module notebooks.

    [:octicons-arrow-right-24: Explore Concepts](concepts/index.md)

    [:octicons-arrow-right-24: Module Notebooks](tutorials/index.md)

</div>
