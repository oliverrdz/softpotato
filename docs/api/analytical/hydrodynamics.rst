Hydrodynamics & Convection Equations (``softpotato.analytical.hydrodynamics``)
==============================================================================

The ``softpotato.analytical.hydrodynamics`` module provides models for hydrodynamic
and convective electrochemical systems, including rotating disk (RDE) and
rotating ring-disk electrode (RRDE) configurations.
