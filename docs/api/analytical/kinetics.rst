Thermodynamics & Interfacial Kinetics (``softpotato.analytical.kinetics``)
==========================================================================

The ``softpotato.analytical.kinetics`` module provides thermodynamic and electrode
kinetic formulations, including Nernst equilibrium, Butler–Volmer, and Tafel models.
